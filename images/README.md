# images/：正文图片资源

[返回项目根目录 README](../README.md)

## 目录职责

`images/` 保存正文需要的照片、截图、示意图和其他位图资源。图片文件应有清晰、稳定的命名，并在使用处说明图号、用途、来源和许可边界。

## 使用约定

优先使用仓库内可追溯的原始或生成资源；外部图片在许可核验并登记到 [参考资料索引](../resources/references.md) 前不纳入发布材料。需要替换图片时同步检查所有正文链接和版权声明，避免留下失效或无来源的图片引用。
