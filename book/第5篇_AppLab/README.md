# 第5篇：App Lab

## 本篇定位

聚焦 Arduino App Lab 的 App、Brick 和可部署项目组织方式。

## 学习目标

理解项目结构、运行、日志、启动项和部署流程。

范围覆盖 App/Brick 组成、项目生命周期、运行日志、启动配置与部署验证；章节编号从本篇重新开始。

建议以**第7章“App Lab 综合部署验证与篇末交接”**收束本篇：将项目声明、目标能力、配置快照、启动与运行证据、健康判定、故障对账、回退条件及人工验收记录串成一次可复核的演练。第1～6章提供这些环节的分项方法，但尚无一章完整走通部署到交接的证据链。当前不预设第8章；若第7章完成后仍有独立且不可并入的主题，再更新目录规划。正文范围收束不等于发布验收完成。

## 前置知识

完成 Linux 与 Python Bridge 篇相关基础，能阅读基本项目配置。
