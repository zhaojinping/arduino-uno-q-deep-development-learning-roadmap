## 目录职责

`book/` 保存学习路线的正文、篇章目录和章节级阅读入口。这里的内容面向读者，应该能从目标、前置条件和实验步骤一路读到可复现的验证结果。

## 入口约定

- `../SUMMARY.md`：全书唯一的篇章与章节顺序入口，后续任务补齐。
- `第1篇_认识UNOQ/README.md`：第一篇的固定入口，后续任务补齐。
- 每个章节目录使用自己的 `README.md`，并遵循 [写作规范](../docs/writing-guidelines.md)。

## 边界

Task 1 只建立正文入口和路径约定，不在此处提前放置未核验的章节、代码或外部材料。正文中的示例应链接到 [code/](../code/README.md)，图示应链接到 [diagrams/](../diagrams/README.md)，来源应登记到 [参考资料索引](../resources/references.md)。
