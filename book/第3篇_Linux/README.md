# 第3篇：Linux

## 本篇定位

聚焦 UNO Q 的 MPU、Debian Linux 及其应用运行环境。

## 学习目标

掌握文件系统、网络、进程、服务、日志、资源、ADB 与 SSH，并理解 Linux 侧与 MCU 侧的分工和安全回滚边界。

## 章节地图

- [第 1 章：Linux 侧开发基础：文件系统、进程与 MCU 边界](./第1章_Linux侧开发基础_文件系统进程与MCU边界.md)——建立 Linux/MPU、MCU、Bridge、文件系统、进程、权限、访问入口和证据等级边界。
- [第 2 章：Linux 设备、网络与服务：从可见到可用](./第2章_Linux设备网络与服务_从可见到可用.md)——建立设备节点、udev、网络分层、NetworkManager、服务状态、日志和 Bridge 结果关联。
- [第 3 章：Linux 可观测性与资源管理：日志、时间与安全回滚](./第3章_Linux可观测性与资源管理_日志时间与安全回滚.md)——建立 journal 字段、时间基准、资源压力、证据归档、远程变更和安全回滚闭环。
- [第 4 章：Linux 远程运维与 Python Bridge：从安全命令到可验证请求](./第4章_Linux远程运维与Python_Bridge_从安全命令到可验证请求.md)——建立 ADB/SSH/App Lab 入口、命令白名单、Python 子进程、请求信封、幂等、结果状态和远程回滚边界。
- [第 5 章：Linux 现场自动化与 Python Bridge：队列、重连与状态缓存](./第5章_Linux现场自动化与Python_Bridge_队列重连与状态缓存.md)——建立有界队列、背压、任务租约、退避重连、缓存 freshness、优雅停止和现场对账边界。
- [第 6 章：Linux 与 Python Bridge 现场测试与性能治理：从基准、压测到故障注入](./第6章_Linux与Python_Bridge现场测试与性能治理_从基准压测到故障注入.md)——建立测试层级、时间与分位数指标、确定性故障注入、性能预算、现场测试窗口和放行门。
- 后续章节：Linux 与 Python Bridge 的部署和性能治理，按本篇内的第 7 章……继续编号。

## 前置知识

完成第一篇基础认知，具备基本命令行和网络概念。
