# 第八篇第3章：离线缓存与补传

本目录使用本书原创的合成遥测数据，离线演示 SQLite 持久化发件箱与确定性恢复流程：

- `offline_telemetry.jsonl`：3 条通过第1章遥测契约的合成事件，不是现场采集数据或 MQTT 抓包。
- `outbox.py`：在显式本地 SQLite 文件中保存事件；按事件键处理未完成事件重入；满队列拒绝新事件而不淘汰旧事件；TTL 到期后报告事件键并删除；以严格 FIFO 和有上限指数退避进行重试。
- `test_offline_outbox.py`：11 项标准库行为测试，覆盖进程重开、边界容量、事件键冲突、TTL、FIFO、重试、结果不确定和写事务失败。

在本目录运行：

```shell
python -B outbox.py
python -B -m unittest -v test_offline_outbox.py
```

不提供参数时，演示只在系统临时目录创建 SQLite 文件并在退出后清理。若传入 `--database`，程序会在明确指定的本地文件中创建或更新数据库；只对教程专用测试路径执行，不要指向业务数据库或保留重要数据的文件。代码没有网络客户端、Broker、后台守护进程或 UNO Q 硬件调用。

`ACKED_REMOVED` 只表示模拟的“发布端到下一跳”确认，不能解释成订阅消费者或业务事务已完成。`UNCERTAIN` 表示发送结果可能未知，队列保留同一事件键和载荷等待补传；下游仍需要复用第2章的持久化幂等账本。测试使用注入时间而非真实等待，不证明断电、文件系统损坏、存储介质寿命或生产 Broker 行为。
