# 离线 IoT 安全策略检查器

本目录提供一个只使用 Python 标准库的教学检查器，用于检查合成设备配置中的身份映射、凭据生命周期、TLS 声明和 MQTT 最小权限规则。配置固定保存在 `profiles.json`；命令行只接受显式参考时间，不读取系统时钟、环境变量或任意输入路径。

检查器的 `PASS` 只表示样例满足本章写明的静态结构和教学策略，不代表实际设备或生产系统安全。拒绝结果也是教学策略判定，不是 Broker、PKI 或网络端点的实测结果。

## 运行示例

在本目录打开终端后执行：

```powershell
python -B policy_linter.py --now "2026-09-24T12:00:00Z"
```

命令按 `profiles.json` 中的顺序输出紧凑 JSON Lines，每行对应一个配置。固定样例中有一个 `PASS` 配置和多个刻意构造的 `DENY` 配置；因此整条演示命令预期返回退出码 `1`，这是样例结果，不是运行故障。

| 退出码 | 含义 |
|---:|---|
| `0` | 所有配置均为 `PASS` |
| `1` | 至少一个配置因教学策略而 `DENY` |
| `2` | 参数、时间、文件读取或 JSON 解析错误；只在标准错误输出稳定问题码 |

## 代码说明

- 用途：离线检查合成的设备身份、TLS 声明、凭据有效期和 MQTT 主题授权策略。
- 运行环境：Python 3.10 或更高版本；在 Windows PowerShell、macOS 或 Linux 终端均可运行。
- 文件位置：本目录的 `policy_linter.py`；唯一输入文件为同目录 `profiles.json`。
- 依赖：Python 标准库 `json`、`datetime`、`pathlib`、`re` 和 `sys`；不需要第三方软件包、Broker 或网络。
- 操作步骤：先进入本目录，再原样执行上方命令。`--now` 是必填参数，只接受秒精度 UTC 时间 `YYYY-MM-DDTHH:MM:SSZ`；命令不会推断当前时间，也不接受输入文件路径。
- 预期输出：标准输出按配置顺序给出 JSONL；本固定样例同时含 `PASS` 与 `DENY` 报告，命令预期退出码为 `1`。以上是示例预期，不是本次实测终端日志。
- 故障排查：`CLI_ARGUMENTS_INVALID` 表示参数缺失或多余；`TIMESTAMP_INVALID` 表示时间格式不符；`INPUT_READ_FAILED` 表示固定样例文件不可读；其他解析错误以稳定问题码报告。错误输出不包含路径、异常详情、配置值或秘密标记。修正输入后重新运行，不要把凭据或真实设备配置放入样例。
- 验证方式：在仓库根目录运行 `python -B -m unittest discover -s "code/第8篇_IoT/第6章_IoT设备身份与安全通信" -p "test_*.py" -v`；检查退出码、每行 JSON 和有意拒绝的用例。运行完整固定样例时，退出码 `1` 是预期行为。

## 固定样例与秘密筛查边界

样例中的设备标识、日期均为虚构，域名使用保留用途的 `example.invalid`，凭据与信任锚只使用 `synthetic://` 引用。文件不包含私钥、密码、令牌、可用证书或真实设备配置。它不可用作生产策略文件。

本章筛查器只识别固定敏感字段名（忽略大小写并归一化 `_`、`-` 和空格）以及若干显著 PEM 私钥头；它不是通用秘密发现工具。扫描深度超过 256 层或访问节点超过 50,000 个时会拒绝输入。拒绝可能表示发现了已知标记，也可能表示筛查未能完整执行；这不等同于确认输入中一定存在秘密。反过来，未命中也不能证明任意格式的秘密不存在。

## 明确不验证的事项

此本地检查器不执行证书验证或密码学证明，不进行真实 TLS 握手，不连接 Broker 或其他网络服务，也不确认 Broker 实际执行了 ACL；不做生产秘密发现，不做 Arduino UNO Q 硬件验证，不验证 MCU/Linux 分工或真实凭据轮换。生产部署仍需独立实施密钥管理、证书校验、服务身份验证、Broker 授权与设备端集成测试。
