# 第八篇第4章：IoT 可观测性与告警

[返回本章正文](../../../book/第8篇_IoT/第4章_IoT可观测性与告警_从设备状态到可操作信号.md)

本目录提供纯 Python 标准库的离线健康快照判定器、4 条人工构造的 JSONL 样例和 14 项行为测试。运行时必须显式提供预期设备身份与固定参考时间，因此同一输入可重复得到同一报告。

程序只读取样例并打印 `LOCAL_SYNTHETIC_ONLY` 报告；不连接 UNO Q、传感器、网络、MQTT Broker、OpenTelemetry Collector 或 Prometheus，也不发送告警、不重试发布、不改变队列、更不控制硬件。90 秒、300 秒、600 秒、80% 与 5 分钟重试次数均是本书演示阈值，不是平台默认值或生产建议。
