# 第七篇第7章：生成式 AI 与工具调用安全边界

本目录提供一个离线、纯 Python 标准库的教学策略门，展示模型提出的工具请求如何先经过本地白名单、参数验证、独立批准与重放检查。本模拟器只改动进程内的虚拟指示灯，不会连接真实模型、网络、Arduino UNO Q、Bridge、MCU、GPIO 或执行器。

## 文件

- `tool_guard.py`：工具白名单、参数校验、单独批准、进程内调用账本、最少审计字段和固定演示 CLI。
- `test_tool_guard.py`：12 项 `unittest` 行为测试，覆盖读取、待批准、执行/拒绝、伪造字段、非法参数、重放、冲突、审计与 CLI 范围声明。

## 环境与运行

- Python 3.10 或更新版本；仅使用标准库。
- 在本目录执行：

  ```shell
  python -B tool_guard.py
  python -B -m unittest -v test_tool_guard.py
  ```

- CLI 输出一行 JSON。演示顺序包括读取虚拟状态、写操作待批准、传入独立教学批准、再阻断相同调用的重放。

## 安全边界

- `OperatorApproval` 只是教学数据结构；`actor` 是普通字符串，不能证明用户身份或授权来源。
- 调用账本只在当前进程内存有效，重启后清空；生产系统需要经认证的批准来源、持久幂等记录、下游权限检查和明确的失效安全策略。
- `dispatch()` 接收已经解析的 Python 对象，不实现 HTTP 接入、原始 JSON 重复键检测、请求大小限制、速率限制、截止时间或代理循环预算。
- 本地测试通过只验证列出的模拟契约，不构成生产安全证明或目标板兼容性证据。
