# 第六篇第2章代码：摄像头接入与视频帧采集

## 代码清单

- [`inspect_capture.py`](inspect_capture.py)：从操作者显式指定的摄像头索引或本地视频文件读取有限帧数，检查返回状态、数组维度与数据类型，并在结束时释放采集对象。

## 运行边界

依赖兼容的 OpenCV Python bindings（导入名 `cv2`）。脚本不扫描设备，不接受 URL、网络流或任意后端管线，不自动配置 MIPI-CSI，也不设置分辨率。摄像头索引由目标系统分配；请先确认相机、载板、系统镜像、驱动和后端的兼容关系。

从本目录运行：

```text
python inspect_capture.py --source camera:0 --frames 5
python inspect_capture.py --source file:/path/to/sample.mp4 --frames 5
```

帧属性查询值只是采集后端报告值；每帧的 `shape` 与 `dtype` 才是本次交付数组的直接观察。读取和初始化可能受后端阻塞，本脚本不承诺跨后端硬超时。程序不显示/保存图像、不写配置、不联网、不操作 GPIO/MCU。

退出码：0 表示有限帧样本通过基本结构校验；2 表示来源参数错误或采集对象未打开；3 表示某帧读取失败/为空；4 表示帧数组结构或类型异常；5 表示 OpenCV 采集异常。命令行参数错误由 argparse 自身报告。
