# code/：可复现实验代码

[返回项目根目录 README](../README.md)

## 目录职责

`code/` 保存与正文配套的 Arduino `.ino` 草图、Linux 侧脚本、配置样例和最小可复现实验。每个示例都应能通过正文给出的运行环境、依赖、步骤和验证方式复现。

## 组织约定

代码按篇章或主题建立清晰的子目录，文件名反映用途并保持稳定；示例的说明优先放在对应目录或章节中。涉及硬件、网络、权限或数据写入的示例必须明确风险、停止条件和回滚方式。

代码文件不替代章节解释，也不在没有说明和验证记录时复制外部仓库内容。新增外部代码前先登记其来源与许可证，再在正文中建立交叉引用。
