# 第三篇 Linux 收束章节设计说明

> 状态：第 8 章已写入并完成仓库层静态验证；UNO Q 现场验证仍未完成
>
> 日期：2026-09-22

## 1. 目标

将第三篇“Linux”从第 1～7 章初稿扩展为一个边界明确、能够交接到后续篇章的完整学习单元。新增的第 8 章不重复第 6 章的性能测试和第 7 章的部署治理，而是把设备盘点、服务观察、Bridge 请求、测试证据、发布回滚和跨篇交接组织成一条可执行的综合运行闭环。

本次“完结”指第三篇正文范围完成并形成可持续校验的初稿，不指已完成 UNO Q 实机、systemd、Python Bridge、MCU 联调或远程写操作验证。

## 2. 范围

### 2.1 包含内容

1. 新增第三篇第 8 章，章节编号从第三篇内部重新计数并使用 `part: 3`、`chapter: 8`。
2. 新增 Fig-23 的 Mermaid 源文件和正文中的图示占位。
3. 更新第三篇 README 的章节地图、学习目标和当前状态。
4. 更新根目录 `SUMMARY.md`，使第三篇目录完整到第 8 章。
5. 更新根目录 `README.md` 的路线、当前进度和验证记录。
6. 更新 `images/第3篇_Linux/README.md` 的图示登记。
7. 在已有官方来源范围内补充正文交叉引用；如新增来源，再同步登记到 `resources/references.md`。

### 2.2 不包含内容

- 不改变前 7 章的章节编号和文件名。
- 不新增第四篇、第五篇或第九篇正文。
- 不把本机静态检查改写为 UNO Q 实机验证。
- 不保存真实凭据、真实网络地址、设备序列号或生产配置。
- 不安装、启用、重启或修改用户设备上的 systemd 服务。
- 不在未获单独授权时向远程 GitHub 推送。

## 3. 第 8 章设计

拟定文件名：

`book/第3篇_Linux/第8章_Linux与Python_Bridge综合运行手册_从预检到交接.md`

章节标题：

`第8章 Linux 与 Python Bridge 综合运行手册：从预检到篇末交接`

章节结构固定为：

1. 学习目标
2. 背景与边界
3. 综合运行的对象、状态和证据等级
4. Fig-23：Linux、Bridge、服务治理与跨篇交接闭环
5. 预检与只读盘点
6. Dry-run 与受控运行
7. 健康门、故障分级与 UNKNOWN 处理
8. 证据包和现场交接
9. 第一个 Python 实验：运行批次与证据清单
10. 第二个 Python 实验：交接门与未决项清单
11. 综合运行手册
12. 故障处理矩阵
13. Linux 与 Python Bridge 综合验证矩阵
14. 与第四篇、第五篇和第九篇的交接
15. 本章验证结果
16. 常见问题
17. 本章小结
18. 延伸阅读与交叉引用

章节中的两个 Python 示例只生成本地、脱敏、可审查的运行记录，不调用 ADB、SSH、systemd、Bridge 或硬件，也不产生远程写入。
